
# Excel Comapany Performance Dashboard

## Project Overview
This project focuses on analyzing sales performance using Microsoft Excel.

The objective is to understand revenue, profitability, customer behaviour, geographical performance, and product category contribution.

## Tools & Technologies
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Power Pivot / DAX (if used)

## Project Workflow
1. Import raw sales data into Excel.
2. Clean and transform data using Power Query.
3. Prepare data for analysis.
4. Create PivotTables for business analysis.
5. Create DAX measures using Power Pivot, if applicable.
6. Develop interactive charts and slicers.
7. Build the final Sales Performance Dashboard.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Customers
- Total Countries
- Total Categories
- Total Profit

## Business Analysis
- Sales and Profit Over Time
- Sales Across Days of the Week
- Male and Female Customer Sales by Category
- Customer Distribution by Country
- Profit Contribution by Category
- Product Contribution to Overall Sales

## Business Objectives
- Identify sales trends and patterns.
- Understand customer purchasing behaviour.
- Identify profitable product categories.
- Analyze geographical customer distribution.
- Support business decision-making.
